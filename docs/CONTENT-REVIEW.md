# 正式版に向けたコンテンツ確認

## 開発方針

軸は「季節と暮らしに合わせて、今日のひと皿を選ぶ」。診断や疾病リスク、個別の治療提案を出さず、季節・食材・調理時間・料理カテゴリで選ぶ。

免責文言だけで適法性を判断しない。本文、画像、体験談、広告、販売への導線を合わせて確認する。現在は販売・課金機能なし。

## 内容の差し替え箇所

## 掲載しないもの

- 効果を保証する文言、病名と改善・予防を結びつける献立。
- 「体質チェック」「参考情報」等の名称だけを根拠にした個人判定。
- 実際には実施していない専門家監修・調理試作の表示。
- 診断・治療・服薬中止等につながる自由回答のAI相談。

## 公開・検証の位置づけ

自動テストは表示・操作・データ保存の検査であり、医療・法律の専門家による適合確認や、人の試遊を代替しない。食物アレルギーや個別の食事制限の安全を保証するものではない。
