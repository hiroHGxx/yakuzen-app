# 正式版に向けたコンテンツ確認

## 開発方針

軸は「薬膳の考え方を、今日の食事選びに生かす」。「いまの自分」を任意の主入口にし、食材・季節からも直接選べる。診断や疾病リスク、個別の治療提案は出さない。詳しくは `docs/REDESIGN.md` を参照。

免責文言だけで適法性を判断しない。本文、画像、体験談、広告、販売への導線を合わせて確認する。現在は販売・課金機能なし。

## 掲載しないもの

- 効果を保証する文言、病名と改善・予防を結びつける献立。
- 「体質チェック」「参考情報」等の名称だけを根拠にした個人判定。
- 実際には実施していない専門家監修・調理試作の表示。
- 診断・治療・服薬中止等につながる自由回答のAI相談。

## 公開・検証の位置づけ

自動テストは表示・操作・データ保存の検査であり、医療・法律の専門家による適合確認や、人の試遊を代替しない。食物アレルギーや個別の食事制限の安全を保証するものではない。

## 今回追加した料理と食材

- 料理：豆ごはん、さつまいもごはん、キャベツと豆腐の味噌汁、にんじんのごま和え、なすの生姜蒸し、りんごのシナモン煮。
- 辞典：米、豆腐、トマト、卵、玉ねぎ、キャベツ、にんじん、なす、さつまいも、りんご。
- 2人分を基準としたサンプル。材料・手順・加熱時間・味・実際の分量は未試作であり、監修・試作の確認対象。地域や品種の旬の差も確認する。
- 写真6点は組み込みimage_genで生成したイメージ。食材の効能や体質判定、既存テーマの理論の変更は追加していない。
