# 「いまの自分」を中心にした再設計

## 情報設計

- 主入口は「いまの自分から、選ぶ」。回答を必須にせず、未選択で食材・季節・手帖へ進める。
- 3つの編集テーマ：冷えが気になる／食欲がわかない／気持ちが張りつめている。
- テーマから、食卓の提案 → 伝統理論の読みもの → 料理と選定理由 → 食材・時間の絞り込みへつなぐ。
- テーマの選択はReactのメモリ内だけ。localStorage・URL・外部APIへ保存／送信しない。再読み込みで解除。
- 料理・食材・保存機能は共通データを使用。既存の手帖保存形式は変更しない。
- 食材や季節の入口へ切り替える際は、前のテーマによる絞り込みを解除する。

## 内容の境界と出典

漢方の概念を薬膳の入門に関連する読みものとして紹介する。漢方と薬膳の同一視、選択に基づく体質・原因の判定、掲載料理の治療効果の推論は行わない。

- 冷えの捉え方：東京医科大学病院 漢方医学センター「冷え症と漢方」（2021年12月）。https://hospinfo.tokyo-med.ac.jp/shinryo/kampo/pdf/column_202112.pdf
- 脾胃の概念：日本漢方生薬製剤協会「胃腸と漢方」。https://www.nikkankyo.org/kampo/colume/009/index.htm
- 気の概念：日本薬学会 薬学用語解説「気血水」（2024年5月13日）。https://www.pharm.or.jp/words/post-82.html

上記は伝統理論の解説の参考資料であり、料理の効果の根拠ではない。本文は独自の要約で、画像や文章の転載はしない。料理の選定は温度・香り・食感・調理時間による編集提案。食材ごとの五性・帰経の断定や、症状に対する効能は追加していない。

正式公開前に国際薬膳師が料理と理論の接続・出典・試作を確認し、必要に応じて法務専門家が画面の流れを含め個別確認する。免責文だけで適法性が保証されるものではない。不調が強い・続く場合の医療相談案内をテーマ結果内にも表示。
