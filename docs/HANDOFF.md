## 合意した設計

- 軸は「薬膳の考え方を、今日の食事選びに生かす」。女性向けの洗練された見た目を目指す。
- ホームは「いまの自分」を主入口にするが、回答は強制しない。「家にある食材」「季節」からも直接入れる。
- 3テーマ：冷えが気になる／食欲がわかない／気持ちが張りつめている。
- 選択後は料理、選定理由、参考資料付きの伝統理論解説を表示し、食材・時間で絞れる。各入口で料理データを共有する。
- テーマ選択はメモリ内のみ。保存・外部送信・URLへの記録なし。再読み込みで解除。
- 生成り・オリーブ・明朝体・余白・料理写真のデザインを維持する。
- 将来はアプリ化も検討するが、現状はPagesのWebアプリ。認証、課金、同期、オフライン対応は未実装。

- 参考資料は理論の説明用であり、掲載料理の効果の根拠ではない。料理の選定は温度・香り・食感・調理時間による編集提案。
- 免責だけで適法性が保証されるわけではない。監修・試作・法的な個別確認は正式公開前の課題。

## 実装の案内

| ファイル | 内容 |
| --- | --- |
| `src/App.tsx` | ナビゲーション、レシピ検索・詳細、辞典、学ぶ、手帖、ダイアログ、天気 |
| `src/Today.tsx` / `src/today.css` | 再設計したホーム、主入口と補助入口、共通のテーマ解説 |
| `src/themes.ts` | 3テーマの文章、参考URL、料理IDと選定理由 |
| `src/data.ts` | 6レシピ、6食材、4記事、クイズ |
| `src/lib.ts` | 検索、分量、手帖データ、日本時間の節気 |
| `src/styles.css` | 全体の既存スタイル |
| `index.html` | 静的なOGP・Xカード・canonical・紹介文 |
| `tests/metadata.test.ts` | OGPの整合性・公開URL・画像の実寸検証 |
| `tests/browser/` | 既存機能と再設計のブラウザ回帰テスト |

- React 19 + TypeScript + Vite。Node.js 22以上、依存関係はロックファイルあり。
- `#today` / `#recipes` / `#learn` / `#notebook` のハッシュ遷移。Viteのbaseは相対パス。
- 手帖のlocalStorageキーは `kinozen-notebook-v1`。保存レシピ・買い物・調理日を保存。既存データを壊さない。
- 天気だけは操作時にOpen-Meteoへ通信する。解析・広告・自由回答AI相談は未実装。
- OGPは全画面共通。公開URLの絶対パスと `images/soup.webp`（1000×667）を指定。SNS実サービスの表示・キャッシュ更新は未確認。

## 検証と起動

```sh
npm ci
npm run dev -- --port 4173
npm test
npm run build
npx playwright install chromium
npx playwright test
npx playwright test --config playwright.pages.config.ts
node scripts/check-publication.mjs
```

- 再設計時：本番ビルド成功、Pages相当の `/yakuzen-app/` でPC・スマホ計16テスト成功。
- OGP追加時：メタデータ検証を含むNodeテスト5件と本番ビルド成功。ブラウザ16件は再設計時の結果で、OGP追加後には再実行していない。
- 320・768・1024pxで4画面の横はみ出しなし。PC・スマホのホームとテーマ結果のスクリーンショットを目視確認済み。
- スマホ検証はChromiumエミュレーション。実機Safari・実ユーザー試遊は未実施。
- ローカル画像は `.local/screenshots/`。ビルド・テスト結果・元画像・依存パッケージはGit対象外。
- CIはpushでビルド・Nodeテスト・Pages配信。ブラウザテストはローカル実行。
- CIにActionsのNode.js 20移行警告あり。配信は成功しており、今回の範囲では更新していない。
