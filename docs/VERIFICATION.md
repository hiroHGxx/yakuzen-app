## 検証結果

- TypeScriptの型検査とVite本番ビルド：成功。
- Nodeのロジックテスト：4件成功。複数食材検索、絞り込み、人数換算と買い物リスト更新、壊れた保存データ、年をまたぐ日本時間の節気を確認。
- Chromiumによるブラウザテスト：PC・スマホ合計12件成功。
- GitHub Pagesと同じ`/yakuzen-app/`で本番ビルドを配信し、上記12件を再確認。
- 320・768・1024pxの幅で4画面の横はみ出しなし。
- 天気API：モックによる成功・失敗と未操作時に通信しないことを確認。実際のOpen-Meteo東京データの取得も成功。
- 画像：6枚を目視、最終WebP合計約0.84MB。PC・スマホのホーム、レシピ、学ぶ、買い物リスト、詳細ダイアログの画像を保存。
- 公開用走査：個人ホーム名、検出対象の秘密情報、20MB超ファイル、画像のEXIF/XMP/IPTCなし。

## 公開用素材

生成PNGをWebPへ変換する際に元画像メタデータを引き継がない形で出力した。元PNGはGit対象外。プロンプトは`docs/image-prompts.json`、配信用画像は`public/images/`。

フォント・アイコン・Reactのライセンスを`public/licenses/`に同梱。依存パッケージのロックファイルを含め、再現可能なビルドにした。
