# 季の膳 — KI NO ZEN

次のセッションで再開する場合は [引き継ぎ情報](docs/HANDOFF.md) を最初に確認してください。

いまのわたしに、今日のひと皿。

季節と暮らしに合わせて「今日のひと皿」を選ぶ、スマートフォン中心の薬膳・食文化アプリ。生成り、深いオリーブ、明朝体、オリジナルの生成料理写真を組み合わせた静かなデザインです。

## 実装したこと

- **今日**：「いまの自分」を主入口に、3つのテーマから料理・選定理由・出典付きの薬膳入門へ。選択は任意で保存・送信しない。食材・季節からも直接探せる。
- **つくる**：料理名・複数食材のAND検索、料理カテゴリ、15分以内・季節の絞り込み。6品の詳細レシピ、1〜6人分への分量変更、手順チェック。
- **学ぶ**：食材辞典6項目、入門記事4本、テーマ別解説3本、二十四節気の一覧、3問のクイズ。
- **手帖**：お気に入り、レシピ単位の買い物リスト、買ったもののチェック・削除、つくった日付の記録。localStorageによる保存、全消去の確認画面。
- **天気**：利用者の操作時だけOpen-Meteoに接続。7都市から選択し気温に合わせた料理のヒントを表示。取得失敗時の表示あり。
- **表示**：PCサイドバー、スマホ下部ナビ、キーボード操作可能なダイアログ、動きを減らすOS設定への対応。

## 起動と検証

Node.js 22以上を使用します。

```sh
npm ci
npm run dev
```

```sh
npm test
npm run build
npx playwright install chromium
npx playwright test
npx playwright test --config playwright.pages.config.ts
```

ブラウザテストはローカルの4173番ポートを使用します。PCとスマホで、写真表示、横はみ出し、検索、人数変更、保存・復元、買い物リスト、作った記録、データ消去、辞典、クイズ、天気の成功・失敗を確認します。画面写真は`.local/screenshots/`に保存され、Gitには含めません。

`playwright.pages.config.ts`はビルド済みの`dist`を4174番ポートの`/yakuzen-app/`で配信し、GitHub Pagesと同じサブディレクトリ構成で全ブラウザテストを実行します。

## GitHub Pages

`.github/workflows/pages.yml`を用意しています。GitHubのリポジトリ設定で **Settings → Pages → Source: GitHub Actions** を選択すると、`main`へのpushでテスト、ビルド、Pages配信を行います。

公開URL：[季の膳](https://hirohgxx.github.io/yakuzen-app/)（2026-09-27 公開プレビュー配信開始）。

`base: './'`とハッシュによる画面切り替えを使用し、`/yakuzen-app/`のようなサブディレクトリ配信に対応しています。外部サービスのAPIキーやビルド用の秘密は不要です。`.env`、ローカル検査画像、node_modules、distはGit対象外です。

## コンテンツの状態

**これは公開プレビューです。国際薬膳師による内容監修・レシピ試作の完了を示すものではありません。** アプリ上でもその状態を表示しています。

- 資格名、認定団体、開発者の氏名・経歴は提供待ちです。架空の監修者を表示しません。
- レシピは6品のサンプルです。人数による材料変更は単純換算であり、加熱時間や炊飯器容量は別途調整が必要です。
- 二十四節気は一般的な日付の目安で、天文学的な年ごとの計算はしていません。
- 食材の五性・帰経など個別分類は監修資料が未提供のため未掲載。体質の自動判定、舌診、症状に基づく個別指導は実装していません。
- アレルゲン表示は補助情報であり、網羅的な安全保証ではありません。調味料を含む商品の表示確認を案内しています。
- 法令適合の保証ではありません。正式版は実際のコンテンツ、販売・広告導線を含めた専門家レビューが必要です。

詳しい更新箇所は [docs/CONTENT-REVIEW.md](docs/CONTENT-REVIEW.md) を参照してください。

## データとプライバシー

手帖はブラウザ内にのみ保存します。ログイン、課金、アクセス解析、広告、病歴や現在地の取得はありません。フォントも自前配信です。

サイト配信時はGitHub Pagesへ、天気ボタン操作時はOpen-Meteoへ通常の通信情報が送信されます。天気には選択都市の固定座標を使用します。天気を一度も開かなければOpen-Meteoへの通信は発生しません。無料APIは非商用利用を前提とするため、商用化時はOpen-Meteoの契約条件を確認してください。

## 画像とフォント

`public/images/`の6枚はこのプロジェクト用に組み込みimage_genツールで新規生成した料理写真です。最終プロンプトは [docs/image-prompts.json](docs/image-prompts.json) に保存しています。元の生成PNGはリポジトリに含めず、WebPに変換してメタデータを引き継がず配信しています。6枚合計で約0.84MBです。

- フォント：Noto Sans JP / Noto Serif JP（Fontsourceから取得、SIL Open Font License）。
- アイコン：Lucide（ISC License）。
- 天気データ：[Open-Meteo](https://open-meteo.com/)（データライセンス：CC BY 4.0）。

配布に必要なフォント・アイコン・Reactのライセンス文は`public/licenses/`に同梱しています。

## 将来のアプリ化

React + TypeScript + Viteを使用し、Web App Manifestを同梱しています。現時点ではオンラインWebアプリで、オフライン動作・端末間同期・ストア配信は実装していません。

将来は、手帖の保存処理をストレージ用モジュールへ切り出し、Capacitorなどによるネイティブアプリ化や、必要に応じたバックエンドを検討できます。監修済みコンテンツを管理画面から更新する構成への拡張も可能です。
